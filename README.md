# Budsy Bloomsy Floral Co.

Website for Kristina's floral business: flower walls, event florals, flower letters and arrangements.

- `index.html`: home page
- `request/`: flower request (intake) form, set up for Netlify Forms
- `palette/`: brand colors and type
- `thanks/`: page shown after the request form is sent
- `styles.css`: shared styles
- `media/`: photos

Deploy by connecting this repo to Netlify (no build step; publish directory is the repo root).
